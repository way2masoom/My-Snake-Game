# 🐍 Snake Game

A classic **Snake Game** built using **HTML**, **CSS**, and **JavaScript**. Control the snake, collect food to grow longer, and achieve the highest score while avoiding collisions with the walls and your own body.

## 🎯 How to Play

1. Open the game.
2. Use the **Arrow Keys** to control the snake.
3. Eat the food to increase your score.
4. Each food item makes the snake longer.
5. Avoid colliding with:
   - The walls
   - The snake's own body
6. Try to achieve the highest score!
